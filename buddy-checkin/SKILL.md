# Buddy 加油站自动签到

## Overview

本技能通过 `scripts/checkin_auto.py`（纯 ctypes，无第三方依赖）自动完成 WorkBuddy 桌面端左下角「Buddy加油站」卡片的每日积分领取。脚本内置五道防线：卡片存在性检测、轮播防护、按钮状态判定、领取后菜单路径复检、异常与退出码约定。

## 使用流程

### 第 1 步：确认前提

- Windows 系统，WorkBuddy 桌面端已登录且进程存活（`WorkBuddy.exe`）
- 屏幕处于可交互状态（**锁屏下 SendInput 无效；仅有显示器关闭不影响——已实测验证**）
- WorkBuddy 窗口建议最大化（宽高低于 1000x900 时脚本会拒绝执行，可用 `--force` 跳过）

### 第 2 步：先 dry-run 确认状态（不点击）

```bash
python "<skill_dir>/scripts/checkin_auto.py"
```

正常输出依次为：
- `窗口已激活 hwnd=... size=...` — 窗口定位成功
- `卡片未显示(左下角只剩头像), 走 头像->菜单->Buddy加油站 路径唤出` — 仅在卡片被收起时出现，脚本自动唤出
- `点击圆点候选N -> SAD=0` — 轮播已停在「Buddy加油站」卡片（SAD≤15）
- `按钮区域平均亮度 = 162 (阈值 100)` — >100 为「立即领取」；≤100 为「今日已领取」直接结束
- `dry-run 模式, 未点击` — dry-run 正常结束

### 第 3 步：真实领取

dry-run 显示「立即领取 -> 可领取」后执行：

```bash
python "<skill_dir>/scripts/checkin_auto.py" --run
```

成功标志：`SUCCESS: 领取完成, 卡片显示 今日已领取`（脚本自动走 头像→菜单→Buddy加油站 重新唤出卡片复检）。

### 退出码约定

| 码 | 含义 |
|---|---|
| 0 | 成功领取 / 今日已领取（无需操作）/ dry-run 正常结束 |
| 1 | 环境问题（无窗口、激活失败、窗口过小、卡片唤不出、轮播 90s 未转回） |
| 2 | 点击后复检异常（需人工看截图） |
| 3 | 首次建模板被特征防护拒绝（标题区无文字特征） |

### 可选参数

- `--menu-path`：领取前先走一遍 头像弹菜单→点 Buddy加油站（一般无需使用）
- `--force`：跳过窗口尺寸校验（小窗口调试用，坐标可能不可靠）

## 关键机制（勿绕过）

1. **卡片可能被收起**：左下角轮播卡片不是永久显示——实测会被收起只剩头像。脚本先检测标题区亮像素占比（<10% 视为无卡片），无卡片时自动走 头像→菜单→Buddy加油站 唤出。
2. **卡片必须先确认再点按钮**：轮播有 3 张（加油站/去邀约/做任务赢积分），各卡按钮位置相同，「立即前往」按钮也是亮色。脚本用标题区域灰度模板 SAD（阈值 15，加油站卡=0、其他卡≈43，跨天稳定）确认卡片。
3. **轮播圆点可点击但热区极小（约 5px）**：未激活圆点 1 中心约 (31,1319)（窗口全屏时）。脚本用 5 个候选坐标依次尝试，全部失败则兜底等待轮播自动转回（90s）。
4. **复检必须走菜单路径**：领取成功后轮播池会变化（实测 3 圆点变 2、卡片自动切走），直接截左下角卡片不可靠。脚本已内置该路径。
5. **坐标自适应**：X 相对窗口左边缘、Y 用「距窗口底部」距离，窗口移动/缩放/换屏均自适应；截图抓整个虚拟桌面，窗口在副屏也有效。

## 资源与日志

- `scripts/title_template.bin` — 标题模板资产（1980 字节）。**不要删除**；若界面改版需重建见排错。
- `scripts/_checkin_log/` — 每次运行只存左下角关键区域小图（约 410KB/张），自动保留最近 24 个；文件名含时间戳与步骤（00_tpl/03_card/03_fail/05_verify）。

## 排错

- **窗口激活失败**：检查 WorkBuddy 是否运行；最小化会被自动还原。
- **`FAIL: 菜单路径未能唤出卡片`**：头像或菜单项坐标漂移（界面改版）。看 `00_nocard.bmp` 截图核对。
- **SAD 一直 >15**：模板过期。删除 `scripts/title_template.bin` 后 dry-run 一次——脚本会自动重建，但需人工核对 `00_tpl.bmp` 截图左下角确实是「Buddy加油站」卡片。
- **亮度判定异常/点击无效**：界面改版坐标漂移。看 `_checkin_log/*.bmp` 定位新坐标，更新脚本顶部常量：`AVATAR / GAS_MENU / CLAIM_BTN`（X, 距底）、`BTN_BOX_XB/YB`、`TITLE_BOX_XB/YB`、`DOT_CANDS`。
- **主题切换后阈值失效**：`BRIGHT_THRESHOLD` 基于当前主题实测（立即领取=162 / 今日已领取=67）。切换深色/浅色主题后若误判，需重新标定该阈值。
- **安全策略拦截**：本技能脚本只用标准库 ctypes；勿用 PowerShell Add-Type（编译被拦）、reg.exe（被拦）、pyautogui/PIL（未安装）。
- **日志膨胀**：正常不会（自动轮转 24 个）。如手工拷贝过旧版全屏日志（14.7MB/张），直接删除即可。

## 风险提示

本技能模拟真实 UI 点击领取用户自己账户的每日积分。客户端更新可能使坐标失效；频繁异常点击可能触发风控。仅限本人账户日常签到使用。
